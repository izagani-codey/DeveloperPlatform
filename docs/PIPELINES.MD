# Development Pipelines

Every feature moves through the same pipeline.

---

## 1. Planning Pipeline

**Goal**

Understand the problem before writing code.

**Input**

- Feature request
- Bug report
- Idea

**Output**

- Feature Specification
- Acceptance Criteria
- Risks
- Definition of Done

Responsible:

- Human
- Architect AI

---

## 2. Implementation Pipeline

**Goal**

Turn the specification into working code.

**Input**

- Approved Feature Specification

**Output**

- Code
- Tests
- Documentation Updates

Responsible:

- Builder AI

---

## 3. Review Pipeline

**Goal**

Ensure correctness and maintainability.

Review Checklist:

- Logic
- Readability
- Security
- Performance
- Coding Standards
- Business Rules

Responsible:

- Reviewer AI
- Human

---

## 4. Validation Pipeline

The human validates.

Required:

- Manual Testing
- Edge Cases
- Acceptance Criteria
- Regression Testing

AI can suggest.

Humans decide.

---

## 5. Deployment Pipeline

Only after validation.

Requirements:

- Tests Passing
- Review Approved
- Documentation Updated
- Commit Complete
