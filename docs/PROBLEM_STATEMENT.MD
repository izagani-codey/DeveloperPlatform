# Problem Statement

## Why this project exists

Modern software development depends heavily on AI.

Current problems:

- AI subscriptions have usage limits.
- Every AI has different strengths.
- Context is lost when switching models.
- Developers repeatedly explain the same project.
- AI-generated code still requires review.
- Knowledge is scattered across conversations.

As projects grow, these issues reduce development speed.

---

## Objective

Create a development platform that allows any AI model to contribute to a project without becoming the source of truth.

The repository owns the knowledge.

AI consumes that knowledge.

The human approves all changes.

---

## Success Criteria

The system should allow a feature to move through this pipeline:

Idea
↓

Planning

↓

Implementation

↓

Review

↓

Testing

↓

Deployment

without requiring the developer to repeatedly explain the project.

---

## Non Goals

This project is NOT:

- another AI chatbot
- another IDE
- another coding assistant

It is a workflow and knowledge system.
